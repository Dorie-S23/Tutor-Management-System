## Meeting 2 — Sprint 1 Planning

**Date:** Monday, 10 August 2026, 5:15 PM · **Duration:** 10 min 28 sec · **Attendees:** all four · **Scribe:** Mkateko

Defined Sprint 1 scope and aligned on tooling/process.

- **Scope:** Basic Tier features as the minimum; Intermediate Tier features tackled where time allows, to ease pressure on Sprint 2. Goal: something tangible, presentable, and deployable by Sprint 1's end.
- **Database:** Supabase (already set up by Mutsawashe) — proceed with it unless a change is required.
- **Architecture:** non-monolithic, i.e. front end and back end kept separate rather than one combined interface (per Software Design patterns; Tagona to share the reference PDF).
- **CI/CD:** build-release cycle — deploy with every meaningful update. The Git methodology doc (shared by Tagona) needs polishing and will be published to the docs site.
- **Deployment:** required by the brief; static hosting via GitHub Pages or Cloudflare Pages. To be investigated and targeted within Sprint 1.
- **Diagrams:** UML not strictly required — client (Brendan) confirmed one diagram explaining how the app works is sufficient.
- **Documentation:** shared responsibility between Dorsa and Mutsawashe, with Mkateko contributing. Git methodology section still outstanding.
- **Communication:** Tagona to join Discord; 2–3 Daily Scrums per week.

**Action items:** join Discord; Tagona shares design-patterns PDF; team begins Basic Tier work immediately; Mkateko sets up scrum schedule; Dorsa & Mutsawashe begin documentation.
