# AI Usage

In line with the COMS3011A AI policy, this page attributes the AI tools used during the development of this project: the tool, the model, and what each was used for. All AI-assisted output was reviewed and tested by the team, and the team takes full responsibility for everything shipped, per the policy.

## How AI was used

| Tool                                         | Model                  | Purpose                               | Used for                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| -------------------------------------------- | ---------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Qoder (AI coding assistant in the Qoder IDE) | _as listed in the IDE_ | Code, editing                         | **Bug fixes and features:** tutor-creation auth-account chain repair, tutor workload endpoint + progress bars, calendar class-occurrence editing, hourly-rate bulk-rates migration, guided-tour restoration, the client-side timetable OCR pipeline (pdf.js + Tesseract.js), and the Gemini timetable reader's return (server-side parse route with multi-model failover, plus the production secret fix). **Documentation:** the database schema page, dev plan, external services page, and user feedback report on this site.                                                                                                                                                                                                                                                                                                                                  |
| Claude Code                                  | Claude Sonnet 5        | Code, editing, testing, documentation | **Bug fixes:** role-based access control on the tutor/student/organiser pages, a calendar duplicate-render race condition, a cross-user localStorage data leak, header/layout regressions after merge conflicts, and N+1 query/performance fixes. **Features:** auto-calculated and validated hour logging (overlap detection, whole-hour rounding), in-app confirmation modals and toast notifications, colour-coded course sessions with a legend, live timetable-clash and weekly-hours-remaining checks, payroll export, and module-application clash blocking. **Testing:** Jest coverage for the calendar, storage layer, registration validation, board keyboard navigation, payroll export, and student volunteer applications, plus a CI workflow to run the suite and a pre-push formatting hook. **Documentation:** sprint and client meeting minutes. |

## Notes

- AI suggestions were always run, tested, and reviewed by a team member before being committed; incorrect or hallucinated output was discarded, not shipped.
- For every module that AI helped build, the owning team member can explain how it works (the final presentation assumes this).
- Anything beyond the tools above (e.g. ChatGPT web for research) should be added to the table as it is used.
