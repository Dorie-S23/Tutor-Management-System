# AI Usage

In line with the COMS3011A AI policy, this page attributes the AI tools used during the development of this project: the tool, the model, and what each was used for. All AI-assisted output was reviewed and tested by the team, and the team takes full responsibility for everything shipped, per the policy.

## How AI was used

| Tool                                         | Model                       | Purpose       | Used for                                                                                                                                                                                                                                                                                                                                                                                               |
| -------------------------------------------- | --------------------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Qoder (AI coding assistant in the Qoder IDE) | _as listed in the IDE_      | Code, editing | **Bug fixes and features:** tutor-creation auth-account chain repair, tutor workload endpoint + progress bars, calendar class-occurrence editing, hourly-rate bulk-rates migration, guided-tour restoration, and the client-side timetable OCR pipeline (pdf.js + Tesseract.js). **Documentation:** the database schema page, dev plan, external services page, and user feedback report on this site. |
| Claude Code                                  | _as configured in the tool_ | Code          | _team to complete — e.g. backend routes, tests, refactors_                                                                                                                                                                                                                                                                                                                                             |

## Notes

- AI suggestions were always run, tested, and reviewed by a team member before being committed; incorrect or hallucinated output was discarded, not shipped.
- For every module that AI helped build, the owning team member can explain how it works (the final presentation assumes this).
- Anything beyond the tools above (e.g. ChatGPT web for research) should be added to the table as it is used.
