# Introduction

A web app for organising tutor allocations to courses — tracking which courses need tutors, matching tutors against courses, and flagging clashes (marks, timetable, hours remaining).

**Live:** [app](https://tutorx.devden.workers.dev) · [docs](https://tutorx-documentation.devden.workers.dev) — both auto-deploy from `main`.

## Tech Stack

### Backend

- **[Node.js](https://nodejs.org/)** — JavaScript runtime the server runs on.
- **[Express 5](https://expressjs.com/)** — web framework that handles HTTP routing and serves the frontend as static files.
- **[Supabase](https://supabase.com/)** (`@supabase/supabase-js`) — hosted Postgres database, used here for data storage and auth session checks.
- **[Resend](https://resend.com)** — transactional email API, called with a plain `fetch` rather than an SDK, which sends the email copy of a notification. Optional: without `RESEND_API_KEY` every notification is in-app only.
- **[dotenv](https://www.npmjs.com/package/dotenv)** — loads environment variables (`SUPABASE_URL`, `SUPABASE_ANON_KEY`, `GEMINI_API_KEY`, `RESEND_API_KEY`, `PORT`) from a local `.env` file.

### Frontend

- **Vanilla HTML/CSS/JS** — no framework. Pages live in `public/html`, styling in `public/css`, and browser logic in `public/js`. Express serves this folder directly (`express.static`).
- **Google Fonts** (Fraunces, Space Grotesk, Inter, IBM Plex Mono) loaded via `<link>` tags.

### Documentation

- **[Docusaurus](https://docusaurus.io/)** — this site. A separate static site generator (React-based) for project documentation, self-contained in `my-docs/` with its own `package.json`.

## How It Fits Together

1. `server.js` starts an Express server and serves everything in `public/` as static files.
2. The browser loads a page from `public/html/` (e.g. `board.html`), which pulls in its stylesheet and script.
3. The page's script (e.g. `board.js`) calls the REST API (e.g. `/api/courses`) to fetch live data.
4. `server/routes/courses.js` handles those API requests and talks to Supabase via `server/supabaseClient.js`.
5. `GET /api/test` is a simple endpoint to check the Supabase connection is alive.

## Running Locally

```bash
npm install
cp .env.example .env     # then fill in your Supabase + Gemini keys
npm start
```

The server runs at `http://localhost:3000` by default (override with `PORT` in `.env`).

## Running the Documentation Site

This site is built separately with Docusaurus, from `my-docs/`:

```bash
cd my-docs
npm install
npm start
```
